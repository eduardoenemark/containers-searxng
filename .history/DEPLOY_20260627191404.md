## 🎯 Objetivo

Pacote auto-contido para migrar o SearXNG de uma VM para um servidor dedicado. Inclui tudo que é necessário para deploy limpo e funcional.

## 📁 Estrutura

```
searxng-8888/
├── docker-compose.yml      # Orquestração (searxng + valkey)
├── .env                    # Variáveis de ambiente
├── config/
│   └── settings.yml        # Config completa com 55 engines
├── scripts/
│   ├── deploy.sh           # Deploy automatizado
│   └── backup.sh           # Backup/restauração
├── .gitignore
└── README.md               # Documentação completa
```

## 🚀 Deploy em Servidor Novo

```bash
# 1. Copiar pasta para o servidor
scp -r /home/mxlinux/projects/searxng-8888 user@servidor-novo:/opt/

# 2. SSH no servidor novo
ssh user@servidor-novo

# 3. Entrar na pasta
cd /opt/searxng-8888

# 4. Executar deploy
./scripts/deploy.sh

# Pronto! SearXNG rodando em http://localhost:8888
```

## ⚙️ Personalização

### Alterar porta
Editar `.env`:
```env
SEARXNG_PORT=9090  # Nova porta
```

### Trocar secret key
```bash
openssl rand -hex 32
# Copiar o resultado para .env -> SEARXNG_SECRET
```

### Acesso externo
Editar `.env`:
```env
SEARXNG_BIND=0.0.0.0  # Ou [::] para IPv6
```

## 🔧 Comandos

```bash
# Deploy completo
./scripts/deploy.sh

# Atualizar versão
./scripts/deploy.sh update

# Backup completo
./scripts/backup.sh full

# Restaurar backup
./scripts/backup.sh restore backups/settings_20260627.yml

# Logs
./scripts/deploy.sh logs

# Status
./scripts/deploy.sh status
```
